# InStride LLC Website

Static one-page website for InStride LLC.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save.
5. GitHub will provide the public Pages URL.

## Before launch
Replace `contact@instride-llc.com` in `index.html` with the preferred InStride business email if different.
